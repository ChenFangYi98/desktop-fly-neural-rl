# 果蝇神经训练实验室：使用与实现说明

本页面把桌面果蝇正在运行的神经模拟、感觉输入和技能策略放在同一处展示。它的目标是让每一层都可观察、可解释、可测试，而不是把模型输出描述成真实果蝇的主观思想。

## 1. 三类信息必须分开理解

| 页面内容 | 来源 | 可以怎样解释 |
|---|---|---|
| 脑点云、神经元身份、连接边 | 项目随附的 FlyWire v783 提取数据 | 解剖位置和图连接数据 |
| 闪光、放电率、传播动画、行为读数 | 668 神经元 LIF（漏电积分发放）模拟 | 此项目模型在当前输入下的实时状态 |
| 技能名称、奖励、正确率、置信度 | 本项目的奖励式策略层 | 模型学到的“条件→动作群”映射 |

传播动画会在发生脉冲时，从该神经元的实际出边中选择强连接进行显示。为了保持帧率，界面不会同时绘制全部连接；动画线条表示加载的连接图中的源和目标，不代表对单根生物轴突的实时成像。

“思想翻译器”同样只根据可观察到的刺激、行为和内部模型状态生成中文描述。它不是意识读取，也不是对主观体验的科学测量。

## 2. 启动

最简单的方法是在项目根目录双击 `一键启动果蝇实验室.vbs`。它会以实验室模式启动：桌面透明果蝇默认隐藏，完整模拟在后台运行，生态观察室和神经训练窗口正常显示。两个窗口右上方/工具栏都有互相切换按钮。

如果希望看原始的桌面宠物模式，也可以在 `windows` 目录打开 PowerShell：

在 `windows` 目录打开 PowerShell：

```powershell
npm install
npm start
```

应用会显示三个部分：

1. 桌面上的果蝇；
2. “果蝇生态观察室”，可投放食物、天敌和控制捕猎；
3. “果蝇神经训练实验室”，用于观察和训练。

如果关闭实验室窗口，它只是隐藏。可从系统托盘菜单重新打开。
托盘中的“显示桌面果蝇/隐藏桌面果蝇”可以随时切换透明覆盖层。

## 3. 实时神经页面

- 左侧点云显示脑解剖位置；亮色的大点是当前模拟回路中的神经元。
- 神经元放电时会闪光，同时沿加载回路中的强出边短暂显示传播线。
- 绿色/青色传播表示兴奋性权重，红色表示抑制性权重。
- 按住鼠标拖动可以旋转大脑；单击一个区域会刺激附近的模拟神经元。
- 右上方每 100 毫秒更新一次模拟时间、累计脉冲和当前行为。
- “神经群放电率”显示全体、逼近视觉、转向、前进、后退、梳理和逃生翼神经群的指数平滑放电率。
- “感觉→大脑→身体”显示左右逼近、气流和步态反馈输入。
- “神经信息交换”最多保留最近 8 条连接传播记录，以免高频放电拖慢页面。

## 4. 训练一个技能

训练器学习一个有限且可验证的映射：当某个条件出现时，选择哪个已识别神经群作为动作输出。

1. 输入技能名称，例如“正面威胁时起飞”。
2. 选择触发条件：左侧威胁、右侧威胁、正面逼近、气流/震动或静止状态。
3. 选择目标动作：起飞、前进、后退、左右转、梳理或抬翼。
4. 点击“开始 700 回合训练”。每回合会在探索动作与当前最佳动作之间选择，正确动作奖励 `+1`，错误动作奖励 `-0.22`，再更新动作价值。
5. 训练结束后检查策略置信度和最近 80 回合正确率。
6. 点击“应用到果蝇”。当选定条件实际发生时，策略会刺激对应神经群，后续活动仍通过原有 LIF 回路传播。
7. 点击“重置”会停止当前训练、删除本地保存的策略，并从果蝇上卸载它。

最后一次训练结果保存在该窗口的 `localStorage` 中。重新启动后会显示已保存结果，但不会自动控制果蝇，必须再次点击“应用到果蝇”。

## 5. 训练的边界

这个实现不能让果蝇“学习任何技能”。可训练能力受以下条件限制：

- 输入必须是系统能检测的五类条件之一；
- 输出必须是回路中已有且能刺激的七类神经动作之一；
- 训练改变的是策略层的动作价值，不会篡改随附的 FlyWire 连接图；
- “置信度”是动作价值的 softmax 归一化结果，不是生物学概率或统计显著性；
- 该仿真适合交互、教学和软件实验，不等同于活体果蝇的学习、记忆或意识。

若要扩展技能，先为新感觉编写可测量的触发器，再将新输出绑定到有明确来源和测试的神经群。不要绕过神经层直接改动物位置，否则无法验证行为是否经过模拟回路产生。

## 6. 障碍躲避游戏训练

在“果蝇生态观察室”点击工具栏中的“🎓 训练躲障”：

1. 场景会切换为包含三道错位墙体的训练路线，蓝圈是起点，黄绿色圆环是终点。
2. 程序执行 2600 回合 Q-learning。果蝇可选择上下左右四个动作；到达终点奖励 `+15`，碰撞惩罚 `-2.5`，每移动一步有小额时间成本，接近终点有小额塑形奖励。
3. 面板实时显示训练回合、最近 100 回合成功率、训练期间累计碰撞，以及探索率变化。
4. 训练通过后，黄色线条显示贪心策略形成的路线，果蝇会自动反复演示。
5. 演示时面板显示左侧、前方和右侧三路距离传感器。绿色表示通畅，黄色表示需要注意，红色表示非常接近障碍。
6. 点击面板右上角 `×` 可退出障碍训练并恢复食物和天敌；点击“重新训练”会清空旧 Q 表，从随机探索重新开始。

障碍训练不是预设路径：自动测试用固定随机序列训练独立 Q 表，然后要求贪心策略抵达终点、路线不经过任何障碍、近期成功率超过 90%。实时页面还通过 Electron 烟雾测试验证按钮确实完成全部 2600 回合并进入演示状态。

## 7. 自动测试

```powershell
npm test
npm run ecosystemsmoke
```

`npm test` 包含五组：神经回路不变量、脑到行为链路、运动回路与腿部力学、奖励训练器收敛、障碍 Q-learning。`npm run ecosystemsmoke` 会启动一个真实但隐藏的 Electron 生态页面并点击训练按钮，验证页面完成 2600 回合。

## 9. 与 Flyhard 项目的关系

本实现借鉴 Flyhard 的核心实验约束：连接图保持固定、输入和输出必须明确、学习参数与回路本身分层、结果可以重复验证。它没有复制 Flyhard 的完整 16.5 万神经元 GPU/CARLA 环境；桌面应用使用现有的轻量 668 神经元实时回路，以便普通 Windows 电脑持续运行并可视化。

## 10. 常见问题

**神经页面没有数据**  
确认 `../data/brain_points.json` 和 `../data/circuit.json` 存在，然后从 `windows` 目录启动。

**应用技能后没有立刻动作**  
技能只在其触发条件成立时运行。例如“正面逼近”要求左右逼近通道同时超过阈值；可在生态环境中让天敌从果蝇正面接近，或在桌面果蝇附近快速移动光标。

**传播动画太快**  
这是毫秒级模拟的降采样显示。文本日志经过 85 毫秒节流，图形最多同时使用 72 条复用线，避免因可视化反过来改变模拟速度。

**想验证具体连接**  
日志会给出源神经类型、目标神经类型和权重。原始节点与边位于 `../data/circuit.json`，可用索引逐项核对。
